# A股高股息长线复利策略执行框架

保守型高股息分析：股息可持续 + 护城河 + 技术位 → **今日可执行推荐**（K≤10 + 排队）。不做组合规划。

**原则**：分红靠 FCF 覆盖（银行/保险用专用表），不是账面利润；买卖以布林为主、估值分位仅少量兜底；现金 ≥20%；数字必须可追溯，缺口则暂停。

命令 / URL / 字段 → [`references/eastmoney-data.md`](references/eastmoney-data.md)。执行前 `opencli doctor`。

**分工**：脚本抓数、硬筛、摊事实卡，并打**数字维**建议分（同类分位 + 宽带宽封顶/封底 + 自身过热帽）。Agent 只打护城河、复核红线、写今日推荐与桌面终报。禁止重打数字维、禁止手算总分、禁止把脚本分当红线终评。

```
Step0 原始 N → 全进 Step1 → 通过 M → 全量评分/红线
→ 仅对 🟢/🟡 拉 K 线/估值分位
→ 前部：今日推荐 K≤10；附录：M 只详报
```

## 执行步骤

### Step 0：动态候选池（失败则整 skill 终止）

必须用东财条件选股现场出池。禁止行业表 / 记忆 / yjfp 凑名单。用户明确单票评估除外。

**脚本（唯一出池路径）**：`run_step0_xuangu.js` — 点「去选股」后扫 Result 页 `el-table`（固定列代码/名称 + 滚动列股息/市值，按行对齐）。条数须等于页内「共 N 只」。来源 `xuangu-result-dom`。

筛条件：**总市值 >1000 亿** + **最新股息率 ≥ 当日中国 10Y 国债 × 2**（上限 100%；国债默认 Investing）。禁止写死 3.5%。

```bash
node scripts/run_step0_xuangu.js -o /tmp/buffett_xuangu_result.json --pool-json /tmp/buffett_pool.json
```

失败（doctor / 打不开 xuangu / 条件无效 / 扫表条数对不上）→ 终止，不得进 Step 1。  
交付：chip、时点、落盘路径、全量 N 只代码。池内 **全部** 进 Step 1，禁止抽样。

### Step 1：硬门槛

对 N 只全检。行业由 `fetch_industry.js` 的东财 `f100` 映射（无 `--industry` 时 Step1 现拉），只写入事实卡作画像参考。禁止用代码名单或简称归类。

**必须全过**：连续现金分红 ≥ 5 年（TTM 股息剔特别分红）；股息率缺失则剔除。市值不再筛。

**企业性质不是门槛**：按 F10 实控人标注中央/地方国企/其他。民企与央国企同一套规则。仅当总分、股息/国债比均相同时，央国企优先。

硬约束不过即剔除，除非护城河极宽并写明补偿理由。PB 是软约束。

### Step 2：质地评分（含红线）

读事实卡。数字维**采用脚本建议档**；同时复核 `red_hints`。踩红线立即 🔴，不再给买入/增持。卡上没有 → 该维 —，整票 ⚠️，不准猜。

```bash
node scripts/fetch_f10_bundle.js --pool /tmp/buffett_pass_pool.json -o /tmp/buffett_f10.json --resume
node scripts/pack_step2_facts.js \
  --step1 /tmp/buffett_step1.json --f10 /tmp/buffett_f10.json --bond /tmp/buffett_bond.json \
  -o /tmp/buffett_step2_facts.md --json /tmp/buffett_step2_facts.json
```

**脚本做**：概况/实控人、派息、ROE/负债/FCF/银行保险专项、quote；`red_lines.js` 机械提示；`score_numeric.js` 数字维建议档 + 护城河代入总分表。  
**脚本不做**：护城河得分、红线定评、今日推荐、桌面终报。

#### 数字维怎么打（脚本，Agent 不要重打）

主尺是**同类分位**，宽带宽只做封顶/封底。画像表里的 ROE/派息/PB 是带宽锚，不是「≥8% 才给 80」的精线。

1. **同类**：同一东财 `f100` 且 ≥4 只；否则升到 A–G。升完仍 <4：不用分位，取带宽下沿，**不给 100**。
2. **分位**：越高越好的指标看「有多少同伴更差」；PB/负债/不良反过来。分位 → 五档 100/80/50/20/0（≥80→100，≥60→80，≥40→50，≥20→20）。
3. **宽带宽**：把分位档夹进 `[min,max]`。例如公用 ROE≥中枢+4 才允许 100；落在中枢附近最多 80、最少 50。FCF 任一年 cover<1 → 该维最多 50。派息落在画像带放宽 ±10pct 内为健康带；略高于上沿且 FCF 盖得住 → 最多 80，不因此否决 🟢。>100% 该维 0，走红线。
4. **自身过热帽**（不是「D 类一律最高 80」）：ROE/派息相对**本公司**近 5–10 年中位数。≥2 倍 → 帽 50；≥1.5 倍 → 帽 80；自身历史分位 ≥80 且 ≥1.3 倍中位数 → 帽 80。稳定高（接近自身中枢）不戴帽，D 类也可以 100。不足 5 年不戴帽。
5. 只打五档 **100 / 80 / 50 / 20 / 0**（缺维 —）。哨兵未核（派息/FCF 量级）→ 该维 —。
6. **护城河由 Agent 打**（点名 F1–F6，点不出 ≤50）。查事实卡「护城河代入总分」表，禁止手算加权。红线未核前该总分只是「若红线不成立」的评级；复核属实则强制 🔴。
7. 本步不看 K 线、估值分位、新闻。不要为打分去抓研报/一致预期。分红承诺卡上没有则不准编。

推翻数字维仅限：哨兵已核单位无误，采用脚本已算好的建议档（仍不许改档）。同类数字接近、分差被带宽/过热拉开时，以脚本理由为准。

| B 运营商 | 电信运营 | 50%–70% | ≥9% | ≤1.5 | ≤55% |
| C 能源混合 | 煤炭、油气 | 40%–70% | ≥10% | ≤1.5 | ≤55% |
| D 强周期 | 钢铁、有色、航运 | 30%–60% | ≥12% | ≤1.0 | ≤60% |
| E 银行/保险 | 银行、保险 | 25%–40% | ≥9% | ≤0.8 | 不看负债率 |

#### 权重表

银行现金流量表口径不同。**E 类银行禁止用 FCF / 净现比 / 负债率**；保险用偿付，不要套银行不良率。

| 非银（A/B/C/D/F/G） | 银行 | 保险 |
|---|---|---|
| FCF 覆盖 25% | 资产质量（不良/拨备）25% | 偿付充足 25% |
| 护城河 25% | 护城河 25% | 护城河 25% |
| 派息 15% | 核充率 `HXYJBCZL` 15% | 偿付趋势（近 2 年）15% |
| ROE(3 年) 15% | 派息 15% | 派息 15% |
| PB 10% | ROE 10% | ROE 10% |
| 负债率 10% | 净息差趋势 10% | 投资收益 `NET_ROI` 趋势 10% |

**派息**：脚本已用宽健康带；略高于上沿且覆盖健康 → 不否决 🟢。>100% 走红线。

**护城河**只打下表；点不出 → 该维 ≤50。ROE/FCF/派息不重复计入。禁止市值/龙头/赛道/景气/卖方评级加分。周期股护城河从严（点不出就 ≤50），但不要因为「是 D 类」就把数字维一律封顶。

| 码 | 类型 | 成立要点 |
|---|---|---|
| F1 | 特许/牌照 | 准入对新进入者实质关闭或极慢 |
| F2 | 稀缺资源 | 流域/矿权/枢纽等不可迁移 |
| F3 | 网络基建 | 重建成本极高、份额自我强化 |
| F4 | 转换成本 | 换供应商贵/慢/有监管绑定 |
| F5 | 成本优势 | 单位成本或负债成本长期优于同行 |
| F6 | 品牌溢价 | ≥3 年提价或毛利溢价，非广告热度 |

**FCF** = 经营现金流 − 资本开支；覆盖率 = FCF / 年度分红。非金融单年覆盖 **>5 或 <-2** → 先复核单位，未复核不得落分。

**企业性质**（脚本推断可推翻）：国务院国资委 / 中央汇金 / 央企集团 → 中央国企；省/市国资委 → 地方国企；其余 → 其他。反例：中国移动、泸州老窖都不得标「其他」。

**数据缺口**：任一计分维缺字段 → ⚠️，动作「数据缺口，暂停评级」。禁止用 50/60/75 凑分。今日推荐只从分数齐且 🟢/🟡 中选。

#### 红线（一票否决）

`red_hints` 须复核后才能定 🔴（银行/保险跳过现金流两条）：

1. 派息率 >100%——注明 `寅吃卯粮 / 盈利骤降但分红维持 / 特别分红`（净利同比腰斩标「盈利骤降」，禁止一律写寅吃卯粮）
2. 经营现金流连续 2 年 < 净利润（优先净现比 <1，否则 OCF<净利）——银行/保险不适用；银行改用：不良率连续 2 年上升 且 拨备跌破 150%
3. FCF 连续 2 年 < 年度分红（cover<1）——银行/保险不适用
4. 净利润亏损仍分红

**评级**（只看代入表总分 + 红线 + 缺口）：⚠️ 缺维不终评；🟢 ≥80；🟡 70–79；🟠 60–69；🔴 <60 或踩红线。总分取自事实卡「护城河代入总分」，禁止手算。

### Step 3：买卖点（布林为主，估值分位少量兜底）

质地（Step 2）回答「能不能拿」；何时动手以技术位为准。只对 🟢/🟡（可加少数排队票）跑 K 线，不必给全部 M 只算布林。

#### 3.1 后复权 K 线（强制）

必须用后复权收盘自算（`fqt=2` / `--adjust backward`）。禁止行情页默认 `fqt=1`、手抄布林。脚本：`fetch_kline_hfq.js` → `calc_bollinger.js`。日/周 window=20、月 window=24，nbdev=2。报告必填 K 线来源。

#### 3.2 主路径：多周期布林

带宽 = (上轨 − 下轨) / 中轨。带宽 **≥ 5%** 时以布林为准：

| 区域 | 定义 | 动作 |
|---|---|---|
| 理想买点 | 月线中～下轨 + 周线下轨附近 + 日线下轨 | 可主路径建仓；建仓后继续下跌且仍在该区，🟢 可可选加仓 |
| 持有区 | 月线中轨上方、上轨下方 | 持有；禁止因「站上中轨」追涨加仓 |
| 减仓区 | 见 Step 4 | 按比例减仓 |

标注 **「信号来源：布林带」**。

#### 3.3 次路径：估值分位（仅技术位不满足时）

仅 🟢/🟡 且出现任一：未到理想买点；带宽 <5%；K 线不够算月线 24 期。近 5 年（不足则用全部并备注；股息分位剔特别分红）：

| 指标 | 可少量布局 | 观望 | 偏贵 |
|---|---|---|---|
| TTM 股息率历史分位（优先） | ≥80 | 60–80 | ≤20 |
| PB 历史分位（交叉） | ≤20 | 20–40 | ≥80 |

冲突以股息率分位为准。脚本 `fetch_valuation_history.js`。算不出分位 → 必须观望，禁止标「估值分位」并给仓位。

分批建仓：单次 ≤ 总资金 **5%**；须 `allow_batch=true`（股息分位≥80；无股息分位时 PB≤20）。不得写成核心底仓或 15% 一笔建仓。标注 **「信号来源：估值分位（原因：___）」**。

### Step 4：动作与仓位

| 评级 | 允许 | 禁止 |
|---|---|---|
| 🟢 | 建仓 / 可选加仓（仅下探） / 持有 | 持有区追涨加仓 |
| 🟡 | 持有；或估值分位分批（单次 ≤5%） | 布林主路径首笔大额建仓；站上中轨追涨 |
| 🟠 | 观察 / 持有（仅用户已持仓） | 新建仓、列入今日可执行买入 |
| 🔴 | 回避新建仓；已持仓可写复核减持/清仓 | 写成持有/建仓/加仓 |

🟢 ≠ 立刻满配：主路径等技术买点；未到则最多分批 ≤5%。

| 动作 | 百分比基数 |
|---|---|
| 建仓 / 加仓 / 目标仓位 / 现金 | **总资金** |
| 减仓 / 清仓部分 | **该票当前市值** |

单票上限建议 ≤15%（护城河极宽可 20%，须备注）。

- **建仓·主路径**（仅 🟢 + 布林理想买点）：最多 15%
- **建仓·次路径**（🟢/🟡 + 估值分位）：单次 ≤5%
- **加仓**：仅 🟢；已有主路径仓；理想买点出现后继续下跌仍在该区；单次 ≤8% 且 ≤已投入；禁止站上中轨再加
- **减仓（布林）**：周中轨 1/10；周上轨 1/5；月上轨 1/3
- **减仓（分位路径）**：股息分位 ≤20 → 减 1/5
- **清仓**：踩红线、FCF 捂不住分红、银行资产质量恶化、护城河破坏

**今日预算**：新买/加仓合计 ≤ 总资金 30%；现金 ≥20%；可执行最多 10 只。排队：总分 → 股息/国债比 → 仅同分时央国企优先。

**目标价**（每票两档，点名操作采用哪一档）：
1. 技术：近端=周中轨；乐观=周/月上轨中更保守者
2. 股息隐含：`(现价×TTM股息率) ÷ 近5年TTM股息中位数`（无中位数则不编）

有布林有效信号 → 操作以技术目标价为主；走估值分位 → 以股息隐含价为主。

税后股息：持股>1 年免税，否则按 10%/20% 提示。每票写下次检视时点。

## 避坑

- 跳过 Step 0 / 截断名单 / 失败改走 yjfp 或凭记忆凑池
- 用代码名单或简称（「电力」「酒」）归行业；必须用东财 `f100`
- DOM 扫表不校验「共 N 只」、或不按固定列+滚动列对齐
- 凭记忆填数字；派息不过哨兵；FCF 极端值不核单位；缺维用 50/60/75 凑分
- 重打数字维或手算总分；忽略「护城河代入总分」表
- 护城河把 ROE/FCF/派息再加权，或仅按市值打分
- D 类数字维一律最高 80；或样本 <4 只仍给 100
- 把画像 ROE 中枢当精线（8.0% 上下差 1 档）
- 派息略高于画像上沿就否决 🟢（覆盖健康则视为纪律好）
- 估值分位当常规大额买点；站上中轨追涨加仓；省略后复权
- 今日推荐 >10 只，或仓位加总不留现金；评级与动作矛盾（尤其 🔴 写持有）
