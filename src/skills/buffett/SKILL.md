# A股高股息长线复利策略执行框架

保守型高股息分析：股息可持续 + 可复现数字质地 + 技术位 → **今日可执行推荐**（K≤10 + 排队）。不做组合规划。

**原则**：**股息提供厚垫，质量决定厚垫能否维持，布林决定何时上车**。分红靠 FCF 覆盖（银行/保险用专用表），不是账面利润；Boll 不进入质地分，只负责买卖时机；现金 ≥20%；数字必须可追溯，缺口则暂停。

每步 **Run** 一行即可执行。flags / URL / 字段 / 完整串联 → [`references/eastmoney-data.md`](references/eastmoney-data.md)。执行前 `opencli doctor`。

**缓存目录**：一律写 [`~/Desktop/temp/`](file:///Users/zhengjiajun/Desktop/temp)（`buffettTmp()` 自动定位并创建），禁止默认写系统 `/tmp` 或仓库 `tmp/`。

**分工**：脚本抓数、硬筛、摊事实卡，并完成**全量数字评分**（同类分位 + 宽带宽 + 自身历史 + 持久性）。Agent 只复核红线、写今日推荐与桌面终报。经营壁垒可作不计分备注。禁止重打数字维、禁止手算总分、禁止把脚本分当红线终评。

```
Step0 原始 N → 全进 Step1 → 通过 M → 全量评分/红线
→ 对全部 M 只拉后复权 K 线并算布林
→ 前部：今日推荐 K≤10（可为 0）；§2 个股全评覆盖全部 M 只
```

#### 数字维怎么打（脚本，Agent 不要重打）

主尺是**同类分位**，宽带宽只做封顶/封底。ROE/ROIC/派息/负债/稳定性阈值只读 `references/anchors.approved.json` 中该票 **f100** 的已批准锚；候选锚未审批不得生效。PB 暂不参加历史校准：有 f100 PB 锚则用；否则用类别软锚（`industry_map.js` CLASS_META）做带宽、同类分位夹段；两者都无才仅同类分位。

1. **同类**：仅同一东财 `f100` 且 ≥4 只；不足 4：不用分位，取带宽下沿，**不给 100**。
2. **分位**：越高越好的指标看「有多少同伴更差」；PB/负债/不良反过来。分位为连续 0–100（**线性**，不再五档跳变）。
3. **宽带宽**：绝对值按 knot **线性插值**得段内 [min,max]，再把连续分位夹进该段。ROE/派息/负债等必须已有该 f100 锚；无锚则该维 —。FCF 任一年 cover<1 → 该维最多 50。派息落在 f100 健康带放宽 ±10pct 内为健康带；略高于上沿且 FCF 盖得住 → 最多 80，不因此否决 🟢。>100% 该维 0，走红线。
4. **自身过热帽**：ROE/派息相对**本公司**近 5–10 年中位数。≥2 倍 → 帽 50；≥1.5 倍 → 帽 80；自身历史分位 ≥80 且 ≥1.3 倍中位数 → 帽 80。不足 5 年不戴帽。
5. 维度得分 **0–100 整数**（线性插值后四舍五入；缺维 —）。趋势/持久性/机械规则同样用 knot 线性插值，不再阶梯跳档。哨兵未核（派息/FCF 量级）→ 该维 —。
6. **总分由脚本直接给出**，禁止 Agent 改档或手算加权。红线未核前只是数字评级；复核 hard 红线属实则强制 🔴。
7. 本步不看 K 线、新闻。不要为打分去抓研报/一致预期。分红承诺卡上没有则不准编。

数字维不得人工推翻。哨兵或源数据有误时应修正/重抓后重新运行脚本，禁止在报告里手改档位或总分。

#### 行业锚（仅 f100，不是硬公式）

行业唯一键是东财 `f100`（如「电力」「白酒」「银行」）。带宽锚来自 `anchors.approved.json` 中对应 f100 的已批准值；**无该 f100 锚则相关维度 —**。事实卡必须打印锚版本与 f100。

##### 长期锚校准（低频维护，不是每次选股都跑）

1. `build_anchor_pool.js` 按 f100 选总市值靠前样本；默认每行业 20 家、市值 ≥200 亿、排除 ST/退市。
2. `calibrate_anchors.js --pool ... --resume` 抓近 10 个完整财年。每家公司至少 5 年有效值；先算公司长期中位/CV/σ，再算该 f100 横截面中位/分位。
3. 单项有效公司数 ≥8 才写入该 f100 候选；不足则该行业不出现在 candidate 中。输出 candidate JSON 与桌面 Markdown 复核报告，**不会自动改变评分**。
4. 人工复核报告后运行 `approve_anchors.js --candidate ... --yes`。日常评分只读 `anchors.approved.json`，并在结果中记录版本、f100 来源和 N。
5. **本阶段不抓、不校准 PB 历史**：无 f100 PB 锚时用类别软锚做带宽（银行/保险约≤0.8），同类分位只能在该段内滑动。

#### 权重表

银行现金流量表口径不同。**银行/保险禁止用 FCF / 净现比 / 负债率**；保险用偿付，不要套银行不良率。

| 非银 | 银行 | 保险 |
|---|---|---|
| FCF 覆盖 25% | 资产质量（不良/拨备）25% | 偿付充足 25% |
| 派息 14% | 核充率 `HXYJBCZL` 14% | 偿付趋势（近 2 年）14% |
| ROE(3 年) 14% | 派息 15% | 派息 15% |
| PB 10% | ROE 10% | ROE 10% |
| 负债率 10% | 净息差 10% | 投资收益 `NET_ROI` 趋势 10% |
| ROIC 持久性 10% | PB 10% | PB 10% |
| 毛利率持久性 7% | 分红纪律 9% | 分红纪律 9% |
| 分红纪律 10% | ROE 稳定性 7% | ROE 稳定性 7% |

**派息**：脚本已用宽健康带；略高于上沿且覆盖健康 → 不否决 🟢。>100% 走红线。

##### 持久性维度（脚本机械评分）

1. **ROIC 持久性（非金融）**：近 5 年 ROIC 中位相对该 f100 已批准 ROIC 锚分档；CV 封顶阈值也取同 f100 锚。较最早年度下降 >30%/50% 封顶 50/20；不足 5 年不给 100。
2. **毛利率持久性（非金融）**：近 5 年标准差按该 f100 已批准阈值分档。较最早年度下降 ≥5/10pct 封顶 50/20；不足 5 年不给 100。
3. **分红纪律（全类）**：从 `DIVIDEND_MAIN` 已实施方案解析「10派 X 元」，同一报告年度的中期/三季/年度分红相加为年度 DPS；禁止用 `MAINFINADATA.TOTAL_SHARE` 回推历史 DPS（该字段可能在历史行重复当前股本）。相邻年度 DPS 下降 >5% 记一次下调；0/1/2/≥3 次对应 100/50/20/0。派息率历史 σ >10/20/30pct 分别封顶 80/50/20；最新 DPS 同比下降 >20% 封顶 20；不足 5 年不给 100，少于 3 年该维缺失。
4. **ROE 稳定性（银行/保险）**：近 5 年 ROE 的 CV 按该 f100 已批准阈值分档。较最早年度下降 >30% 封顶 50；不足 5 年不给 100。
5. **金融 PB**：有 f100 PB 锚则带宽+分位；否则类别软锚带宽+分位。当前校准阶段仍不抓 PB 历史。
6. **净息差（银行）**：主尺是最新净息差水平（knot 1.0/1.3/1.6/2.1% → 20/50/80/100 + 同类分位夹段）。两年变动只在明显弱于同业中位时封顶（≥0.20pct 且弱于同业 → 帽 20；>0.08pct 且弱于同业 → 帽 80）；同业一起收窄不罚。

经营壁垒（牌照、资源、网络、转换成本、成本、品牌）只允许作为**不计分备注**，不得改变脚本总分、评级、排序或硬门槛结果。

**FCF** = 经营现金流 − 资本开支；覆盖率 = FCF / 年度分红。非金融单年覆盖 **>5 或 <-2** → 先复核单位，未复核不得落分。

**企业性质**（脚本推断可推翻）：国务院国资委 / 中央汇金 / 央企集团 → 中央国企；省/市国资委 → 地方国企；其余 → 其他。反例：中国移动、泸州老窖都不得标「其他」。

**数据缺口**：任一计分维缺字段 → ⚠️，动作「数据缺口，暂停评级」。禁止用 50/60/75 凑分。今日推荐只从分数齐且 🟢/🟡 中选。

#### 红线（一票否决）

`red_hints`（hard）须复核后才能定 🔴；`soft_hints` 不自动一票否决（银行/保险跳过现金流两条）：

1. 派息率 >100%——分支：
   - 净利同比腰斩 → hard「盈利骤降但分红维持」
   - 近两年 FCF 覆盖均 ≥1 → soft「特别分红倾向」（派息维仍 0，但不强制 🔴）
   - 任一年 cover<1 → hard「寅吃卯粮：FCF盖不住」
   - 无 cover → soft「须人工区分」（不自动否决）
2. 经营现金流连续 2 年 < 净利润（优先净现比 <1，否则 OCF<净利）——银行/保险不适用；银行改用：不良率连续 2 年上升 且 拨备跌破 150%
3. FCF 连续 2 年 < 年度分红（cover<1）——银行/保险不适用
4. 净利润亏损仍分红

**FCF 分红分母口径**：优先 `COMPRE.TOTAL_DIVIDEND`；若与「净利×派息」隐含值之比 <1/3，视 COMPRE 残缺改用隐含，并按年独立决策（禁止一年 COMPRE、一年隐含混用放大量级哨兵）。

**评级**（只看脚本总分 + hard 红线 + 缺口）：⚠️ 缺维不终评；🟢 ≥80；🟡 70–79；🟠 60–69；🔴 <60 或踩 **hard** 红线。`soft_hints`（如特别分红倾向）不自动 🔴。总分取自事实卡，禁止手算。

### Step 3：买卖点（仅布林；已删除估值分位次路径）

#### 3.2 多周期布林（唯一买卖路径）

带宽 = (上轨 − 下轨) / 中轨。带宽 **≥ 5%** 时按表执行；带宽 **<5%**、或 K 线不够算月线 24 期 → **观望**，不得用其它指标替代建仓。

| 区域 | 定义 | 动作 |
|---|---|---|
| 可尝试批量建仓 | **必须**月线中轨附近 + 日线中～下轨（含两端）。周线下轨附近为**更优、非必须** | 仅 🟢 可主路径尝试批量建仓；同条件时周线也在下轨附近者优先进今日买入。批量建仓后继续下跌、日线仍在中～下轨且月线未明显站上中轨，🟢 可可选加仓 |
| 持有区 | 月线已明显离开中轨附近、走在中轨上方至上轨下方 | 持有；禁止因「站上中轨」追涨加仓 |
| 减仓区 | 见 Step 4 | 按比例减仓 |

**月线中轨附近**：收盘贴近月线中轨（含中轨；可略低于或略高于中轨），尚未明显远离中轨走入月线上半带。  
**日线中～下轨**：下轨 ≤ 日线收盘 ≤ 中轨。  
**周线**：未到下轨附近仍允许尝试批量建仓，报告须标注「周线未到下轨」；到了则标注「周线共振」。

标注 **「信号来源：布林带」**。未到可尝试批量建仓条件的 🟢/🟡 → 排队或在 §2 全评写观望/持有，**不进今日可执行买入**（除非已持仓写持有/减仓）。

### Step 4：动作与仓位

| 评级 | 允许 | 禁止 |
|---|---|---|
| 🟢 | 批量建仓（仅可尝试批量建仓条件）/ 可选加仓（仅下探）/ 持有 | 持有区追涨加仓；未到可尝试批量建仓条件却新建仓 |
| 🟡 | 持有（仅用户已持仓）；观望 | 新建仓、布林主路径批量建仓、任何「分批布局」 |
| 🟠 | 观察 / 持有（仅用户已持仓） | 新建仓、列入今日可执行买入 |
| 🔴 | 回避新建仓；已持仓可写复核减持/清仓 | 写成持有/建仓/加仓 |

🟢 ≠ 立刻满配：必须等布林可尝试批量建仓条件（月线中轨附近 + 日线中～下轨）；未到则观望，**不得**用估值分位薄仓代替。周线未到下轨也可尝试，但同条件优先周线共振。

| 动作 | 百分比基数 |
|---|---|
| 批量建仓 / 加仓 / 目标仓位 / 现金 | **总资金** |
| 减仓 / 清仓部分 | **该票当前市值** |

单票上限建议 ≤15%（脚本总分 ≥90、无 hard 红线时可 20%，须备注）。

- **批量建仓**（仅 🟢 + 布林可尝试批量建仓：月线中轨附近 + 日线中～下轨）：最多 15%；周线下轨附近为更优，非硬门槛

## 避坑

- 跳过 Step 0 / 截断名单 / 失败改走 yjfp 或凭记忆凑池
- 未跑本步 Run 或未落盘就进下一步；不要在本文件扩写完整串联，flags 以 eastmoney-data.md 为准
- 用代码名单或简称（「电力」「酒」）归行业；必须用东财 `f100`
- DOM 扫表不校验「共 N 只」、或不按固定列+滚动列对齐
- 凭记忆填数字；派息不过哨兵；FCF 极端值不核单位；缺维用 50/60/75 凑分
- 重打数字维、手算总分，或用经营壁垒备注修改评分/排序
- 把 ROE/FCF/派息以其他名称重复加权，或仅按市值打分
- D 类数字维一律最高 80；或样本 <4 只仍给 100
- 把画像 ROE 中枢当精线（8.0% 上下差 1 档）
- 派息略高于画像上沿就否决 🟢（覆盖健康则视为纪律好）
- 用估值分位/`allow_batch`/股息隐含价给新建仓或「分批」；站上中轨追涨加仓；省略后复权
- 只给 🟢/🟡 拉 K 线、§2 对其余票写「未拉 K 线（非🟢/🟡）」
- 未到可尝试批量建仓条件仍凑今日买入表；今日推荐 >10 只，或仓位加总不留现金；评级与动作矛盾（尤其 🔴 写持有、🟡 写批量建仓）
- 交叉验证套模板；把短评与详报拆成两套、或 §2 只写推荐票丢掉其余 M 只；报告不落盘
