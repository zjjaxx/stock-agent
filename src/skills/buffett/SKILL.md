# A股高股息长线复利策略执行框架

保守型高股息分析：股息可持续 + 可复现数字质地 + 技术位 → **今日建仓建议**（全样本同业第1且布林到位）。不做组合规划。

**原则**：**股息提供厚垫，质量看同类分位，布林决定何时动手，明显红线一票否决今日建议**。分红靠 FCF 覆盖（银行/保险/证券用专用表），不是账面利润；Boll 不进入质地分。今日名单 = 每个东财 `f100` 里**全样本（硬筛池 M）总分第 1、且布林到位、且无 hard 红线 / ⚠️** 的票；冠军未到买点则该行业今日为空，**禁止用低分替补**。跨行业不比总分。数字必须可追溯，缺口则暂停终评并不得入今日名单。不做仓位预算。

每步 **Run** 一行即可执行。flags / URL / 字段 / 完整串联 → [`references/eastmoney-data.md`](references/eastmoney-data.md)。执行前 `opencli doctor`。

**缓存目录**：一律写 [`~/Desktop/temp/`](file:///Users/zhengjiajun/Desktop/temp)（`buffettTmp()` 自动定位并创建），禁止默认写系统 `/tmp` 或仓库 `tmp/`。

**分工**：脚本抓数、硬筛、摊事实卡，并完成**全量数字评分**（同类分位；红线机械提示另算）。`gen_buffett_report.js` 只输出数字/技术/操作骨架；Agent 复核红线、**逐票撰写巴菲特交叉验证与主要风险**、完善桌面终报。经营壁垒可作不计分备注。禁止重打数字维、禁止手算总分、禁止把脚本分当红线终评。

```
Step0 原始 N → 全进 Step1 → 通过 M → 全量评分/红线
→ 对全部 M 只拉后复权 K 线并算布林
→ 前部：今日建仓建议（每个 f100 仅当全样本第1布林到位才取 1 只 + 无 hard 红线；可为 0；禁止低分替补）；§2 个股全评覆盖全部 M 只
```

#### 数字维怎么打（脚本，Agent 不要重打）

主尺是**硬筛通过池 M 内、同一东财 f100 的同类分位**（连续 0–100）。银/保/证/非金权重表分开算。绝对值 knot、宽带宽夹段、自身过热帽**不再进入得分**。明显红线仍走 `red_hints`。

1. **同类**：仅同一东财 `f100`，样本=硬筛通过池 M。有效同行 n≥2 用同行分位；**n=1（或该维有效同行 <2）→ 改用自身历史分位**；自身历史有效年数 **<3 → 该维缺维 → 整票 ⚠️**（不再给中性 50）。同分用平均秩。
2. **分位**：越高越好看「有多少同伴更差」；PB / 负债 / 不良 / DPS 下调次数 / 毛利率 σ / ROE CV 反过来。得分 = 分位四舍五入为 0–100 整数。
3. **绝对红线仍保留**：派息 >100% → 该维 0，并走红线。FCF 任一年 cover<1 → 该维最多 50。哨兵未核（派息/FCF 量级）→ 该维 —。
4. **持久性/趋势**同样改成分位：ROIC 用 5 年中位（越高越好）；毛利率用 5 年 σ（越低越好）；分红纪律用 DPS 下调次数（越少越好）；ROE 稳定性用 CV（越低越好）；偿付趋势用两年变动；保险净/总投资用水平分位；银行 NIM 用两年变动分位。
5. **总分由脚本直接给出**，禁止 Agent 改档或手算加权。展示为同行 **第 k / n**（同一 f100；并列共享名次）。复核 hard 红线属实则终评回避、不入今日建议。禁止再用 🟢🟡🟠🔴 上色。
6. 本步不看 K 线、新闻。不要为打分去抓研报/一致预期。分红承诺卡上没有则不准编。

数字维不得人工推翻。哨兵或源数据有误时应修正/重抓后重新运行脚本，禁止在报告里手改档位或总分。

##### 持久性维度（脚本机械评分）

1. **ROIC 持久性（非金融）**：近 5 年 ROIC 中位，在本 f100 内越高越好。不足 3 年该维缺失。
2. **毛利率持久性（非金融）**：近 5 年标准差，在本 f100 内越低越好。不足 3 年该维缺失。
3. **分红纪律（全类）**：从 `DIVIDEND_MAIN` 已实施方案解析「10派 X 元」，同一报告年度的中期/三季/年度分红相加为年度 DPS；禁止用 `MAINFINADATA.TOTAL_SHARE` 回推历史 DPS。相邻年度 DPS 下降 >5% 记一次下调；下调次数在本 f100 内越少越好。少于 3 年该维缺失。
4. **ROE 稳定性（银行/保险/证券）**：近 5 年 ROE 的 CV，在本 f100 内越低越好。不足 3 年该维缺失。
5. **金融 PB**：只看池内同类分位（越低越好）；不抓 PB 历史。n=1 无自身 PB 史 → 该维缺维。
6. **净息差（银行）**：两年 NIM 变动的同类分位（越高越好：收窄越少/扩张越好）。最新 NIM 水平只作备注，不进得分。
7. **不良生成（银行）**：年报不良余额增量 / 上一年贷款总额，同类分位越低越好。缺核销，为净额口径。
8. **偏离度（银行）**：东财 `OVERDUE_LOANS` / `NON_PERFORMING_LOAN`，同类分位越低越好。口径是逾期贷款合计/不良，**不是**严格的逾期90天以上。
9. **非息占比（银行）**：利润表 `(营业总收入 − 利息净收入) / 营业总收入`，同类分位越高越好。
10. **偿付充足（保险）**：综合偿付充足率的同类分位（越高越好）。
11. **偿付趋势（保险）**：两年百分点变动的同类分位（越高越好）。东财无风险综合评级(IRR)时作资本轨迹替代。
12. **NBV 增速（保险）**：寿险新业务价值同比增速同类分位（越高越好）。
13. **NBV 率（保险）**：东财 `NBV_RATE` 同类分位（越高越好）；营运利润/EV 无字段时的质量替代。
14. **净/总投资收益（保险）**：`NET_ROI` / `TOTAL_ROI` 水平同类分位（越高越好）。年报 `TOTAL_ROI` 空时用同年度中报/三季回退。
15. **风险覆盖 / 资本杠杆（证券）**：`RISK_COVERAGE` / `CAPITAL_LEVERAGE_RATIO`，越高越好。
16. **质押保障（证券）**：`ZYGDSYLZQJZB` 履约保障比例，越高越好（非质押余额/净资产敞口）。
17. **两融/自营/手续费（证券）**：利息收入同比、投资收益同比、手续费/营收与手续费同比（无市占与自营收益率时的代理）。
18. **股息增长（公用事业）**：近两年 DPS 同比增速，同类分位越高越好。
19. **利息保障 / 应收周转（公用事业）**：`INTEREST_COVERAGE_RATIO` 越高越好；`YSZKZZTS` 越低越好。
20. **经营现金流质量（公用事业）**：经营现金流/净利润，替代 FCF 覆盖重权。
21. **盈利增速（公用事业）**：营收同比与归母净利同比均值。
22. **周期热度（资源）**：最新毛利率在自身近 5 年中的分位，越高越警惕（商品价格分位代理）。
23. **毛利水平 / 有息杠杆 / Capex 纪律（资源）**：5 年毛利中位；`INTEREST_DEBT_RATIO`；资本开支/经营现金流。
24. **经营现金流质量（资源）**：经营现金流/净利润（无 OCF/利息绝对额时）。

经营壁垒（牌照、资源、网络、转换成本、成本、品牌）只允许作为**不计分备注**，不得改变脚本总分、排名、排序或硬门槛结果。

**FCF** = 经营现金流 − 资本开支；覆盖率 = FCF / 年度分红。非金融单年覆盖 **>5 或 <-2** → 先复核单位，未复核不得落分。

**数据缺口**：任一计分维缺字段 → ⚠️，动作「数据缺口，暂停终评」。禁止用 50/60/75 凑分。今日建仓建议**排除** ⚠️ 与 hard 红线。

#### 红线（一票否决）

`red_hints`（hard）须复核后才能定终评回避；`soft_hints` 不自动一票否决（银行/保险/证券跳过现金流两条）：

1. 派息率 >100%——分支：
   - 净利同比腰斩 → hard「盈利骤降但分红维持」
   - 近两年 FCF 覆盖均 ≥1 → soft「特别分红倾向」（派息维仍 0，但不强制否决）
   - 任一年 cover<1 → hard「寅吃卯粮：FCF盖不住」
   - 无 cover → soft「须人工区分」（不自动否决）
2. 经营现金流连续 2 年 < 净利润（优先净现比 <1，否则 OCF<净利）——银行/保险/证券不适用；银行改用：不良率连续 2 年上升 且 拨备跌破 150%
3. FCF 连续 2 年 < 年度分红（cover<1）——银行/保险/证券不适用
4. 净利润亏损仍分红

**FCF 分红分母口径**：优先 `COMPRE.TOTAL_DIVIDEND`；若与「净利×派息」隐含值之比 <1/3，视 COMPRE 残缺改用隐含，并按年独立决策（禁止一年 COMPRE、一年隐含混用放大量级哨兵）。

**排名**（只看脚本总分 + 缺口）：⚠️ 缺维不终评、不排名；否则同一 f100 内按加权总分写 **第 k / n**（并列共享名次）。hard 红线不改名次，只挡今日建议与终评。`soft_hints` 不改变排名。总分取自事实卡，禁止手算。禁止 🟢🟡🟠🔴。

### Step 3：买卖点（仅布林；已删除估值分位次路径）

质地（Step 2）回答「质地如何」；**今日建仓建议** = 每个 `f100` 内**全样本总分第 1**，且布林到位、无 hard 红线 / ⚠️。冠军未到买点则该行业今日不推荐（禁止低分替补）。跨行业不比总分。K 线与布林对**全部 M 只**都跑。

**禁止**：用股息率/PB 历史分位、`allow_batch`、`fetch_valuation_history.js` 给建仓建议；禁止把「估值分位」写成信号来源。未到可尝试批量建仓条件 → **观望**，§1 允许 K=0。

#### 3.1 后复权 K 线（强制）

必须用后复权收盘自算（`fqt=2` / `--adjust backward`）。禁止行情页默认 `fqt=1`、手抄布林。日/周 window=20、月 window=24，nbdev=2。报告必填 K 线来源。无后复权 K 线落盘不得写布林信号、不得给建仓建议。

Run（硬筛通过池全量，禁止按排名抽样）：
```bash
node scripts/fetch_kline_pool.js --pool ~/Desktop/temp/buffett_pass_pool.json --resume
```
单票调试仍可用 `fetch_kline_hfq.js` + `calc_bollinger.js`。flags 见 [`eastmoney-data.md`](references/eastmoney-data.md) §布林。

#### 3.2 多周期布林（唯一买卖路径）

带宽 = (上轨 − 下轨) / 中轨。**周线**带宽 **≥ 5%** 时按表执行；带宽 **<5%**、或周/月 K 线不够 → **观望**，不得用其它指标替代建仓。日线只作展示，**不进**建仓门槛。

| 区域 | 定义 | 动作 |
|---|---|---|
| 可尝试批量建仓 | **必须**周线下轨附近 + 月线中轨～下轨 | 技术到位且为全样本同业第1、无 hard/⚠️ 才写**建仓建议** |
| 未到买点 | 周线未到下轨附近；或月线未落在中～下；或周线带宽<5% | **观望** |

**边界一律相对股价 5%**（不再用半带宽 1/4）：

**周线下轨附近**：
- 收盘 ≤ 周线下轨（含跌破）算到位
- 略高：`(收盘−下轨)/下轨 ≤ 5%`

**月线中轨～下轨**：
- 目标落在中轨与下轨之间（含两端）
- 略高中轨：`(收盘−中轨)/中轨 ≤ 5%`
- 略低下轨：`(下轨−收盘)/下轨 ≤ 5%`
- 等价区间：`下轨×0.95 ≤ 收盘 ≤ 中轨×1.05`

标注 **「信号来源：布林带」**。未到可尝试批量建仓条件 → 在 §2 写**观望**，**不写建仓建议**。布林到位但 hard 红线 / ⚠️ / 同业未居首 → 同样写观望，原因写在操作栏。

### Step 4：动作

操作只允许 **建仓建议** 或 **观望**。禁止加仓、减仓、清仓、持有。

| 布林 | 写入 | 禁止 |
|---|---|---|
| 技术到位且全样本同业第1且无 hard/⚠️ | **建仓建议**，标明全样本同业第1+布林 | hard 红线仍写建仓建议；非第1即使到位也只观望 |
| 未到位，或同业已有更高分到位票，或 hard/⚠️ | **观望** | 用估值分位或其他指标凑建仓建议 |

**是否写新建仓建议** = 该 `f100` 全样本总分第1，且布林到位、无 hard/⚠️。必须等周线下轨附近 + 月线中～下轨（边界均≤5%）；未到则观望（即使第1未到位也不用第2替补）。每个行业最多 1 只，允许 K=0。不写仓位比例、不写资金预算。

- **建仓建议**（全样本同业第1 + 布林到位：周下+月中～下 + 无 hard 红线）：本次操作写「建仓建议（全样本同业第1+布林）」
- **观望**：其余所有情况（未到位、非全样本第1、hard 红线、⚠️、带宽过窄、K 线不足）

无合格票则 K=0。未入今日名单者原因写在 §2 操作栏（布林结论 / 同业未居首 / hard 红线）。

**目标价**（操作采用技术档；后复权轨勿与未复权现价直接比绝对价）：
1. 近端 = 周中轨；乐观 = 周/月上轨中更保守者
2. 禁止为写「股息隐含价」去跑估值分位脚本；无可靠中枢则不编隐含价

税后股息：持股>1 年免税，否则按 10%/20% 提示。每票写下次检视时点。

## 避坑

- 跳过 Step 0 / 截断名单 / 失败改走 yjfp 或凭记忆凑池
- 未跑本步 Run 或未落盘就进下一步；不要在本文件扩写完整串联，flags 以 eastmoney-data.md 为准
- 用代码名单或简称（「电力」「酒」）归行业；必须用东财 `f100`
- DOM 扫表不校验「共 N 只」、或不按固定列+滚动列对齐
- 凭记忆填数字；派息不过哨兵；FCF 极端值不核单位；缺维用 50/60/75 凑分
- 重打数字维、手算总分，或用经营壁垒备注修改评分/排序
- 把 ROE/FCF/派息以其他名称重复加权，或仅按市值打分
- D 类数字维一律最高 80；或 n=1 却无自身历史仍硬给 50（应缺维 ⚠️）
- 用 knot/夹段/过热帽改写脚本分位得分；或继续依赖已删除的 anchors.approved.json
- 样本 <2 只仍给极端 0/100 且不走自身历史分位
- 用估值分位/`allow_batch`/股息隐含价给建仓建议或「分批」；省略后复权
- 只给部分票拉 K 线、§2 对其余票写「未拉 K 线」
- 用 🟢🟡🟠🔴 给分位总分上色（应写第 k / n）
- 未到可尝试批量建仓条件仍凑今日建仓建议；hard 红线或 ⚠️ 仍写入今日建议；用低分替补顶替未到位的同业第1；用跨行业总分截断今日名单
- 交叉验证套模板；脚本 `gen_buffett_report.js` 不得机械生成交叉验证/风险（须 Agent 现写）
