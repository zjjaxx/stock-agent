# A股右侧交易执行框架

右侧交易分析：大市值出池 + **笑傲牛熊六条件买入清单**（Stan Weinstein）→ **今日建仓建议**。不做组合规划，不做基本面筛选，**不做质地评分 / 估值分位 / 股息或分红分析**。

**原则**：**只在趋势已经转向、且有量能确认之后才动手**。今日名单 = 池内**条件 6 通过且突破/回踩买点成立**的票（条件1 大盘、条件2 行业仅作参考提示）；允许 K=0。数字必须可追溯。不做仓位预算。

**右侧交易意味着放弃「便宜」这个理由**：不看 PE/PB、不看股息率、不看 ROE 或分红连续性。价格与成交量是唯一证据，估值低不构成买入理由，估值高也不构成否决理由。

每步 **Run** 一行即可执行。flags / URL / 字段 / 完整串联 → [`references/eastmoney-data.md`](references/eastmoney-data.md)。执行前 `opencli doctor`。

**缓存目录**：一律写 [`~/Desktop/temp/`](file:///Users/zhengjiajun/Desktop/temp)（`tmpPath()` 自动定位并创建），禁止默认写系统 `/tmp` 或仓库 `tmp/`。

**分工**：脚本抓数、判技术位、出报告骨架。`gen_report.js` 只输出池内基础信息/六条件/操作骨架；Agent **逐票撰写主要风险**、完善桌面终报。

```
Step0 出池 N（总市值 >1000 亿）
→ Step1 行业标注（东财 f100）
→ Step2：拉大盘+行业上下文 → 对全部 N 只拉前复权（判技术位）+ 后复权 K 线 → 今日建仓建议 K 只
→ 前部+分册终报（风险由 Agent 现写）
```

### Step 2：笑傲牛熊六条件买入清单（唯一买卖路径）

温斯坦的顺序是**先大盘、再行业、最后个股**。对**全部 N 只**逐条判这六条。其中**条件1 大盘、条件2 行业只作参考建议，不纳入必须符合的要素**——大盘或行业走弱时买点照给，但结论里必须带逆势/逆行业提示（减小仓位、止损从严）。放行门槛是**条件 6**。

| # | 条件 | 量化口径 | 角色 |
|---|---|---|---|
| **1** | 整个市场的趋势向好 | 沪深300 周收盘站上 MA30W（30 周**加权**均线，见 2.3），且 MA30W 近 5 周向上（>0%） | **参考项**，不否决买点；不过时报告须写逆势提示 |
| **2** | 股票所在行业也表现不错 | 东财 `f100` 对应板块指数站上 MA30W 且均线不向下；另报相对沪深300 的 RS | **参考项**，不否决买点；不过时报告须写逆行业提示 |
| **3** | 向上突破阻力区并站上 MA30W，且上方阻力相比之下最小 | **阶段1 底座**：突破前须满足——更早有下跌、底座内停止创新低、均线由跌转平/刚转升（突破前一周斜率 −1.5%～+3%、前 26 周均线涨幅 ≤+8%）；**突破本身**：近 8 周内周收盘突破 30 周阻力区上沿；收盘 ≥ MA30W；距均线 ≤12%；近 104 周中周高价压在现价之上的比例 ≤20% | 突破买点 |
| **4** | 单周量能 ≥ 过去几个月平均周量的 2 倍（越高越好）；或近 3–4 周合计 ≥ 同跨度均量 2 倍，且突破周本身必须放量 | 本周或突破周量比 ≥2.0；或近 4 周合计/（26 周均量×4）≥2.0 且突破周量比 ≥1.2 | 突破买点 |
| **5** | 回撤到 MA30W 附近，且回调时成交量明显萎缩 | **前置**：近 52 周内确有一次**阶段1→2**放量突破（突破周量比 ≥**2.0**，与条件4 同门槛，且通过条件3 同款底座校验）；**本周**：距均线 −3%～+5%，均线仍向上，近 3 周均量/26 周均量 ≤0.8，且前 26 周均线 ≥+3% | 回踩买点 |
| **6** | 相对强度在零轴之上，或由负转正 | Mansfield RS =（股价/沪深300）÷ 自身 52 周均值 −1；>0 或近 8 周由负转正可买；**<0 且近 4 周继续下行（形态差）→ 禁止买入** | **前置 + 一票否决** |

**买点只有两个**：条件 **6** 通过后，再满足 **3+4 = 突破买点**，或满足 **5 = 回踩买点**。其余一律观望。条件1、2 不参与放行，只改变仓位与止损的松紧。

**阶段1 底座是突破的前提**：温斯坦突破买点 = 长期下跌后停止创新低 → 低位横盘 → 30 周均线由跌转平 → 放量向上突破阻力区并站上均线，且上方阻力相比最小。阶段2 中途再创新高、或高位横盘后的「突破」，一律不算条件3。回踩买点的前置突破也必须通过同一套底座校验——没有阶段1→2 的真突破，就没有合法的第二买点。

**回踩必须有前置突破**：回踩买的是「一次已完成的阶段1→2 放量突破」的第二次机会，不是任意一根贴着均线的缩量周。30 周均线滞后于股价，阶段2 翻头进阶段3/4 的头几周同样表现为「均线仍向上 + 缩量跌向均线」，光靠「前 26 周均线 ≥+3%」区分不开。故条件5 增设前置项：近 52 周内必须存在一次量比 ≥**2.0**（与条件4 同门槛）**且带阶段1 底座**的突破。报告须写出该突破在几周前、量比多少、底座依据。

**倍数越高越好**：条件4 达标只是及格线，报告须写出实际倍数，2 倍与 4 倍不能等同处理。

**禁止**：用布林带、估值分位、PE/PB 绝对值门槛、股息率、ROE、分红连续性给买卖信号；**禁止出目标位**（近端/量度目标一律不写）。技术位无法判定（周 bar 不足 36 根）或 RS 上下文缺失 → **观望**，总览允许 K=0（大盘/行业上下文缺失只影响提示语，不拦买点）。

#### 2.3 均线口径：30 周**加权**均线（WMA）

原书第 13 页讲原理时用简单平均举例，但第 25 页说明他实际看的 Mansfield 图表**用的是加权 30 周均线**（离当前越近权重越高），书里全部案例图都是这种。故本 skill 默认 **WMA30**：最近一周权重 30、最远一周权重 1，除以权重和 465。日线口径对应 WMA150。

个股、沪深300、行业板块三层用同一口径，`--ma-type sma` 可整体切回简单均线做对照。**例外**：Mansfield 相对强度的 52 周基准线按其原定义仍用简单平均，不随主均线变化。

加权均线转向更快（代价是锯齿更多），这会实打实改变判定——同一只票 SMA 下「前 26 周均线 +0.41%、趋势未确立」，WMA 下可能变成 +3.91%、趋势已确立。**报告里的 MA 数值必须与盘面同口径对照**，行情软件默认叠加的常是 SMA 或 EMA，肉眼比对前先把均线类型切成 WMA。

#### 2.4 阶段作为背景（不再是买卖门槛）

30 周均线的四阶段仍然写进报告，用于说明"现在在牛熊的哪一段"，但**买卖只认六条件**。

| 阶段 | 判断依据 | 策略 |
|---|---|---|
| **阶段1 底部盘整** | 前 26 周均线走平或先跌后平；股价在 MA30W 附近横向震荡 | 观望，记录阻力区上沿作触发价 |
| **阶段2 上升** | MA30W 近 5 周向上（>+1%），股价在均线上方（轻微跌破 ≤3% 仍算回踩） | 可操作区，但仍须六条件齐备才建仓 |
| **阶段3 顶部派发** | 前 26 周均线先涨后平（斜率 ≤±1%）；股价高位反复、距 52 周高点 >−25% | 禁止新建仓 |
| **阶段4 下跌** | 股价在 MA30W 之下且均线近 5 周向下（<−1%） | 严禁抄底，清仓持币 |

阶段1 与阶段3 都表现为「均线走平」，用**前 26 周均线变动**区分：先跌后平 = 阶段1，先涨后平 = 阶段3。

配套写死：**止损参考** = min(30 周阻力区下沿, MA30W) × 0.97；**触发价** = 阻力区上沿（须放量 2 倍站上）。**不写目标位。**

行情 PE/PB **不进入**技术位判定、也不拦今日建仓。标注 **「信号来源：笑傲牛熊六条件（30 周均线 + 相对强度）」**。

### Step 3：动作

今日名单里操作只允许 **建仓建议** 或 **观望**。禁止加仓、减仓、清仓、持有。

| 情形 | 写入 | 禁止 |
|---|---|---|
| 6 通过，且 3+4 成立 | **建仓建议（突破买点）**，写明突破周量比倍数；条件1/2 未过须附逆势/逆行业提示 | 用估值或市值反推建仓 |
| 6 通过，且 5 成立 | **建仓建议（回踩买点）**，写明前置突破在几周前/量比多少 + 本次回调缩量倍数；条件1/2 未过须附提示 | 把「未缩量的贴均线」或「无前置放量突破的贴均线」当回踩买点 |
| 条件6 为负值且形态差 | **观望（禁止买入）**，明确写出这是一票否决 | 因为估值低或市值大就放行 |
| 条件2 未过（行业在 MA30W 之下） | 买点照给，但结论必须附**逆行业提示**：减小仓位、止损从严 | 因为行业弱就直接否掉买点；或反过来对逆行业买入只字不提 |
| 条件1 未过（大盘在 MA30W 之下） | 买点照给，但结论必须附**逆势提示**：减小仓位、止损收紧到阻力区下沿 | 因为大盘弱就直接否掉买点；或反过来对逆势买入只字不提 |
| 3、4 差一点（如量比 1.6 未达 2） | **观望**，写出差多少、触发价是多少 | 把「接近达标」写成达标 |
| 上下文缺失 / K 线不足 | **观望**，写「条件 X 未知」 | 把「未知」当「通过」 |

**是否写新建仓建议** = 条件 6 前置 + 突破/回踩买点（**不看**条件1/2、**不看**任何基本面）。允许 K=0。不写仓位比例、不写资金预算。

每票必须写全三件事：**六条件逐条结论（含实测数字）** → **所处阶段与依据** → **后续操作**（触发价、止损参考、离场信号）。

**风控**（前复权口径，与现价同量级）：
1. 止损参考 = min(30 周阻力区下沿, MA30W) × 0.97
2. 离场信号 = 周收盘跌破 MA30W 且均线转平/向下；或相对强度跌回零轴之下并持续走弱
3. **不写目标位**：近端目标、量度目标一律不出现在报告里

每票写下次检视时点。

## 避坑

- 跳过 Step 0 / 截断名单 / 失败改凭记忆凑池
- 未跑本步 Run 或未落盘就进下一步；不要在本文件扩写完整串联，flags 以 eastmoney-data.md 为准
- 用代码名单或简称（「电力」「酒」）归行业；必须用东财 `f100`
- DOM 扫表不校验「共 N 只」、或不按固定列+滚动列对齐
- **在选股器里加基本面条件**：Step0 只有市值一条；股息率/PE/PB/ROE/分红一律不加
- 用估值分位、股息率、ROE、分红连续性给建仓建议或「分批」；省略前复权
- 重新引入布林带（下轨/中轨/带宽）当买卖门槛——已整体删除，只认六条件
- **把行业走弱当硬门槛否掉买点**，或反过来在行业走弱时给出买点却不写逆行业提示——两者都错（条件2 与条件1 同为参考项）
- **把条件1 当硬门槛否掉买点**，或反过来在大盘走弱时给出买点却不写逆势提示——两者都错
- **把上下文缺失当通过**：没跑 `fetch_market_context.js` 导致条件6（RS）无法计算时，写「未知」并观望；条件1/2 缺失只写「未知（参考）」，不拦买点
- **放宽量能门槛**：条件4 是 **2 倍**不是 1.5 倍；「接近 2 倍」不算达标，且必须写出实际倍数
- **把「贴着均线 + 缩量」直接当回踩买点**：条件5 有前置项——近 52 周内必须有过一次量比 ≥**2.0** 的**阶段1→2**突破。均线滞后，翻头初期长得和健康回踩一样，没有前置真突破的贴均线一律观望
- **放宽前置突破量能**：条件5 的前置突破与条件4 同为 **2 倍**，不是 1.5 倍；「接近 2 倍」不算达标
- **把阶段2 中途新高当成突破买点**：条件3 要求突破前是阶段1 底座（均线由跌转平、停止创新低、前26周均线涨幅不大）。均线已涨一大截后再创新高，是趋势延续不是底部突破
- **忽略相对强度的一票否决**：RS 为负且近 4 周继续下行时禁止买入，不因市值大、估值低而放行
- **写目标位**：近端目标/量度目标一律不写，只写触发价与止损参考
- 只给部分票拉 K 线、§2 对其余票写「未拉 K 线」；池子大不是抽样的理由，用 `--resume` 续跑
- 只写结论不写实测数字（量比多少倍、RS 多少、上方阻力占比多少）
- 用后复权序列判技术位；用日线单周期代替 30 周均线
- **把 30 周均线当成简单均线**：默认口径是**加权**（WMA30，对应日线 WMA150）；与盘面比对前先把行情软件的均线类型切过来，别拿 SMA/EMA 的读数质疑报告数值
- 脚本 `gen_report.js` 不得机械生成风险段（须 Agent 现写）
- 重新引入质地评分、五维估值、同业第1、候补、PE/PB 偏贵闸门
