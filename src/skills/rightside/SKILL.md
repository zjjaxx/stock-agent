# 沪深300 · 中证红利 · 红利低波｜择时定投 vs 无脑定投回测

总资金 **20 万**，日定投额 **500**，按 **3 年一个周期**对比两套策略在沪深300、中证红利与红利低波上的收益、回撤、牛熊差异。

**原则**：数字必须来自落盘 K 线 + 脚本回测；禁止凭记忆编收益。报告写清标的、复权、布林参数、有无前视。

**缓存目录**：一律写 [`~/Desktop/temp/`](file:///Users/zhengjiajun/Desktop/temp)（`tmpPath()`），禁止默认写系统 `/tmp` 或仓库 `tmp/`。

```
Step0 拉日线（沪深300 + 中证红利 + 红利低波）
→ Step1 算周/月布林
→ Step2 跑回测（择时 / 无脑 × 三标的 × 3 年窗）
→ Step3 生成对比表报告
```

## 策略定义（写死，禁止改口径后装作同一回测）

| 参数 | 值 |
|---|---|
| 总资金 | 200,000 元（初始现金） |
| 单日定投 | 500 元（现金不足则买剩余或跳过） |
| 标的 | 沪深300ETF `510300` · 中证红利ETF `515080` · 红利低波ETF `512890`（一律前复权） |
| 布林 | 周期 20、标准差倍数 2；周线中轨 / 月线上轨 |
| 周期 | 非重叠 3 年窗 + 全样本；按窗内买入持有涨跌幅标牛/熊 |

### 策略 A · 布林择时定投

1. **买**：当日收盘 **低于** 最近一根**已收盘周线**布林**中轨** → 用现金定投 500（可买份额 = 500 / 收盘价）。
2. **卖**：持仓市值 **> 10 万** 且当日收盘 **高于** 最近一根**已收盘月线**布林**上轨** → 卖出持仓份额的 **1/5**，所得回现金。
3. **底仓保护**：持仓市值 **≤ 10 万** → **不卖**。

### 策略 B · 无脑定投

每个交易日定投 500（现金允许时），**从不卖出**。

现金耗尽后两策略都只持仓不动（择时若卖出释体现金，可继续买）。

**防前视**：日信号只用「上一根已收盘」的周/月布林，不用当周/当月未收盘 bar。

## 执行步骤

执行前 `opencli doctor`。脚本目录相对本 SKILL：`scripts/`。

### Step 0：拉日线

```bash
node scripts/fetch_dca_universe.js
# 可选：--symbols hs300,hldf,zzhl  --limit 5000  -o ~/Desktop/temp/
```

落盘：

| 文件 | 内容 |
|---|---|
| `dca_hs300_day.json` | 沪深300ETF `510300` 前复权日线 |
| `dca_zzhl_day.json` | 中证红利ETF `515080` 前复权日线 |
| `dca_hldf_day.json` | 红利低波ETF `512890` 前复权日线 |
| `dca_hldf_idx_day.json` | 红利低波100 `930955` 指数（对照，可选） |

缺文件不得进 Step 1。

### Step 1：周/月布林

```bash
node scripts/calc_bollinger.js ~/Desktop/temp/dca_hs300_day.json
node scripts/calc_bollinger.js ~/Desktop/temp/dca_zzhl_day.json
node scripts/calc_bollinger.js ~/Desktop/temp/dca_hldf_day.json
```

落盘 `{stem}_boll.json`：日线映射的 `week_mid` / `month_upper`（已收盘）、完整周/月带。

### Step 2：回测

```bash
node scripts/run_backtest.js \
  --capital 200000 --daily 500 --floor 100000 \
  --window-years 3 \
  -o ~/Desktop/temp/dca_backtest_result.json
```

产出每标的 × 每策略 × 每 3 年窗（及全样本）的：终值、投入、现金、CAGR、最大回撤、买卖次数、相对买入持有超额、牛熊标签。

### Step 3：报告

```bash
node scripts/gen_report.js \
  --result ~/Desktop/temp/dca_backtest_result.json \
  -o ~/Desktop/dca-compare-YYYYMMDDHHmm/
```

入口读 `00-总览.md`。对话末尾给目录绝对路径。

一键串联：

```bash
node scripts/run_all.js
```

## 报告必须含的表

1. **全样本总览**：两标的 × 择时/无脑 — 本金、终值、持仓、现金、收益率、CAGR、最大回撤、买卖次数  
2. **3 年窗对比**：每窗收益率 / 回撤；窗内标牛/熊/震荡
3. **牛市 vs 熊市汇总**：择时与无脑各自的平均收益
4. **标的对比**：同策略下沪深300 vs 红利低波
5. **口径备注**：secid、复权、布林参数、前视规则、数据起止；本金固定，终值=持仓+现金

## 避坑

- 用未收盘当周/当月布林做当日信号（前视）
- 凭记忆填收益率或「大概回撤」
- 把指数点位当 ETF 份额却不说明代理关系
- 现金未建模（假装永远有钱定投）
- 底仓 ≤10 万仍卖出，或 >10 万却按全仓卖
- 3 年窗边界含糊、牛熊标签不写判定规则

## 边界

研究回测，不构成投资建议。接口失败时声明数据缺口，禁止用训练数据顶替。
